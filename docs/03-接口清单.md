# 03 · 接口清单

所有请求：`Content-Type: application/json`，body = `base64(AES(json))`。
所有响应：`base64(AES(json))`，解密后统一结构：

```json
{"code": 0, "message": "success", "requestId": "<uuid>", "data": {}}
```
| code | 含义 |
|---|---|
| `0` | 成功 |
| `-1` | 参数缺失 / 通用失败 |
| `-2` | 业务拒绝（额度/权益不足等） |
| `-3` | 处理失败 |
| `-10001` | `packageName` 不正确 |
| `-10002` | `uuid` 不正确 |
| `-10003` | `accountId` 不正确 |
| `-10004` | `appUserId` 不正确 |
| `-10011` | `accountToken` 不正确 |
| `-20018` | `ProductId List Info cannot be empty` |
| `-20019` | `Vip Type Info cannot be empty` |

## C. AI 任务（host: `https://iqe.inmelo.app`）

**URL 构造**（`v60/b->c` 反编译）：

```java
url = domain + "/api/ai2/" + modelType + (isTest ? "-test" : "") + "/task/" + action;
// action ∈ { create, query, cancel, createBatch }   (v60/b$c)
```

| 端点 | 参数 |
|---|---|
| `POST /api/ai2/{modelType}/task/create` | 见下 |
| `POST /api/ai2/{modelType}/task/query` | `resMd5` + 身份 |
| `POST /api/ai2/{modelType}/task/cancel` | `resMd5` + 身份 |
| `POST /api/ai2/{modelType}/task/createBatch` | 批量 |
| `POST /api/ai2/accessflag/task/queryUnusedCount` | `appUserId, accessFlags, androidId, uuid, vipType` |

### enhance（`modelType = "lowlight"`）create 参数

| 字段 | 值 | 来源 |
|---|---|---|
| `modelType` | `"lowlight"` | 硬编码 |
| `resUrl` | 资源标识/URL | |
| `resSize` | `文件字节 / 1024` | long |
| `resMd5` | 上传文件 MD5 | |
| `resLength` | `0.0` | double |
| `bucket` | `stn2_ai_gen` / `stn_inmelo_ai` | `aiTaskConfig.bucket` |
| `resolution` | `"宽*高"`（**分隔符是 `*`**） | 如 `1280*720` |
| `vipType` | int | 由 VIP 状态推导 |
| `accessFlags` | 字符串 | 如 `0501.9991.00101` |

create 额外自动附加（`v60/b->a()`）：`integrityToken`、`purchaseToken`、`paymentPlatform`。

### 实测对照（同一身份 / 同一 DTO / 只换 action）

```
POST /api/ai2/lowlight/task/query   {"resMd5":"d41d8cd98f00b204e9800998ecf8427e"}  -> code 0  success
POST /api/ai2/lowlight/task/cancel  {"resMd5":"d41d8cd98f00b204e9800998ecf8427e"}  -> code 0  success
POST /api/ai2/lowlight/task/create  (完整参数)                                     -> code -2 Processing error
```

## D. 上传服务（host: `https://fsbridge.appbyte.ltd`，**明文 JSON**）

| 端点 | 说明 |
|---|---|
| `POST /api/upload/init` | 初始化上传，返回 offset / 上传目标 |
| `POST /api/upload/chunk` | 分块上传，Header 带 `Range`，响应带 `file-md5` |
| `POST /api/upload/file` | 整文件上传 |
| `POST /api/upload/progress` | 查询进度 |

实体：`AiTaskUploadInfo(filePath, cloudResId)`；返回 `ChunkedQueryResult(nextOffset, fileMd5)`。
注意：**该服务 body 不走 AES 信封**，但参数结构未完全恢复（`init` 需正确 DTO，缺失时返回 `{"code":-1,"message":"Processing error","requestId":null}`，`requestId:null` 即代表请求未被识别）。
