## 2. 服务拓扑

```
┌──────────────────────────── 客户端 (Android) ────────────────────────────┐
│  Retrofit/OkHttp                                                          │
│      │  请求体 = base64( AES-128-ECB(JSON) )                              │
│      │  响应体 = base64( AES-128-ECB(JSON) )   ← 命中 Controller 才加密    │
│      ▼                                                                    │
│  libsafe_auth.so  (JNI: nativeGetEncodeText / nativeGetDecodeText)        │
│  libcer.so        (APK 签名白名单校验，RSA-1024 raw verify)               │
│  libelamods.so    (仅 Mod 版存在：native_jvm hook 引擎)                   │
└──────────────────────────────────────────────────────────────────────────┘
        │                    │                        │
        ▼                    ▼                        ▼
 android.inshot.cc     iqe.inmelo.app          fsbridge.appbyte.ltd
 (iap3 账号/额度)      (ai2 AI 任务)            (文件上传，明文 JSON)
        │                    │                        │
        └────────── 同一后端集群（Spring Boot + Google LB）──────────┘
                             │
              ┌──────────────┴──────────────┐
              ▼                             ▼
      gs://stn2_ai_gen               cdn.appbyte.ltd / aicdn.appbyte.ltd
      gs://stn_inmelo_ai             (模型 / 模板 / 结果 CDN)
```

> **重要**：`iap3` 与 `ai2` 虽然同集群，但**路由不互通**：
> `/api/iap3/*` 只在 `android.inshot.cc` 命中；`/api/ai2/*` 只在 `iqe.inmelo.app` 命中。
> 走错 host 一律 404（且 404 是**明文** Spring 错误，可当路由探针用）。

## 5. 请求身份快照

所有业务请求携带（`i9/e` 构造）：

```
packageName  uuid  androidId  appUserId  accountId  appVersion  deviceToken
gaId  adjustId  advertisingId  purchaseToken  integrityToken  language  locate
hasNotificationPermission
```

其中 `uuid` 为客户端生成，`accountId` **客户端自定义**，`appUserId` 由服务端在 signIn 时下发。
